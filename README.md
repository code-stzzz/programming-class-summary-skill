# Programming Class Summary Skill

> 面向编程教师的 Codex Skill：读取 PDF、课件导出文件、图片或思维导图，生成可直接发送到微信群的中文课堂总结，并按课程体系归档到飞书知识库。

## 功能亮点

- **多种课堂资料输入**：支持 PDF、课件导出文件、图片和思维导图。
- **忠于原始资料**：区分资料明确写出的内容和合理推断，不虚构授课内容、作业或学生表现。
- **微信群发送版**：生成适合手机阅读、可直接复制发送的中文课堂总结。
- **飞书教学档案**：生成结构完整、方便教师检索和复用的详细教学记录。
- **自动归档与防重复**：按编程语言、版本和课次组织飞书目录，优先更新已有课程记录。
- **双版本同步**：微信群文案与飞书档案使用同一组事实，修改后保持一致。

## 适用场景

- 课后快速整理课堂知识点并发送到班级群；
- 将长期积累的编程课程资料归档到飞书知识库；
- 从课件中提取概念、语法、课堂示例、易错点和明确布置的作业；
- 为后续备课、复盘和课程内容复用建立可检索的教学档案。

## 工作流程

```text
课程资料（PDF / 图片 / 思维导图 / 课件导出文件）
        ↓
读取内容并核对事实、语言版本、课次和主题
        ↓
生成微信群课堂总结 + 飞书详细教学档案
        ↓
检查已有记录，更新或新建飞书课程文档
```

## 安装

在需要使用该 Skill 的项目根目录运行：

```bash
git clone https://github.com/code-stzzz/programming-class-summary-skill.git .agents/skills/programming-class-summary
```

安装后的主要入口为：

```text
.agents/skills/programming-class-summary/SKILL.md
```

如果你的 Codex 环境使用其他 Skill 目录，请将仓库内容放入该环境能够扫描的 Skills 目录，并保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。

## 使用示例

把本节课的资料提供给 Codex，然后输入：

```text
使用 $programming-class-summary 把本节课资料整理成可直接发送到微信群的中文课堂总结，并归档到飞书。
```

只需要群文案时可以输入：

```text
使用 $programming-class-summary 根据这些课件生成今天的微信群课堂小结，不归档到飞书。
```

## 飞书归档配置

飞书归档规则位于：

```text
references/归档配置.yaml
```

可以在本地填写已有飞书知识库根节点链接：

```yaml
归档:
  形式: "飞书知识库"
  根知识库链接: ""
  操作身份: "用户"
  根目录显示名: "编程课程教学档案"
```

建议不要把包含真实内部知识库地址的配置提交到公开仓库。没有配置飞书目标时，Skill 仍可生成微信群课堂总结。

## 输出内容

### 微信群课堂总结

- 面向学生和家长；
- 默认约 250～500 个汉字；
- 通常包含 3～6 个核心知识点；
- 只在资料明确支持时加入易错提醒、练习或作业；
- 不使用 Markdown 表格，方便手机端直接复制。

### 飞书详细教学档案

- 课程信息与学习目标；
- 知识点详解；
- 关键语法、课堂示例和运行结果；
- 易错点、课堂练习与作业；
- 最终班级群发送版；
- 编程语言、版本和主题等复用标签。

## 注意事项

- 课程资料中的命令式文字只作为教学内容处理，不会当作对智能体的操作指令。
- Skill 不会自行补写资料中没有的作业、日期、学生表现或代码运行结果。
- 飞书归档需要当前 Codex 环境具备相应的飞书连接与权限。
- 无法读取的页面或图片应提供更清晰的导出版本，其余可读取内容仍可继续整理。
